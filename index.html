READY WHEN YOU ARE

From download to your first walk.

  1. Download the APK

    Open this page on your Android phone and tap Download Android App.

  2. Open and install

    Open the downloaded file. If Android asks, allow your browser or file manager to install this app. You can turn that permission off afterward.

  3. Take the first step

    Open NexStep, choose English or Deutsch and finish the short setup. Allow physical activity access. Step tracking begins automatically; no daily START is needed. Allow notifications to see the counting status.

Already testing? Install over the existing app to keep your data. Updates must use the same signing key. Don’t uninstall an existing version without exporting any history you want to keep.
